# 🧩 Sudoku Quest — Go Sudoku

A lively Sudoku web game and solver powered by Go, HTML, CSS and JavaScript.

## ✨ What's new in v2

- 🎮 Easy, Medium and Hard difficulty modes
- ⏱️ Live game timer
- 🏆 Score system and streak tracking
- 💡 Three hints per puzzle
- ✓ Instant board checking with incorrect-cell highlighting
- 🧠 One-click solver
- ↻ Reset and ✨ New Game controls
- ⌨️ Keyboard number entry and arrow-key navigation
- 🎯 Peer highlighting for the active row, column and 3×3 box
- 🌙 Dark mode / ☀️ light mode with saved preference
- 🏅 Achievement feedback
- 📱 Responsive mobile-friendly interface
- 🔒 Stronger backend validation for invalid Sudoku boards

## 🚀 Run locally

Make sure Go is installed, then from the project folder:

```bash
go run main.go
```

Open **http://localhost:8080** in your browser.

## 🛠️ Stack

- Go — HTTP server, puzzle generation and solver
- HTML — interface
- CSS — responsive game UI
- JavaScript — gameplay, timer, scoring and interactions

## 🎯 Roadmap

Future upgrades can include daily challenges, puzzle history, sound effects, animated win celebrations, leaderboards, notes/pencil marks, undo/redo, and multiple Sudoku variants.
